Task Manager API (Backend Assignment)

Hi! This project is a scalable REST API with authentication and role-based access, built as part of a backend developer internship assignment.
The goal was to design a clean, secure, and modular backend system along with a simple frontend to interact with the APIs.
Features :
Authentication & Authorization :
User Registration & Login
Password hashing using BCrypt
JWT-based authentication
Role-based access control (USER / ADMIN)
Task Management (CRUD):
Create, read, update, delete tasks
Users can manage their own tasks
Admin can access all users and tasks
Backend Best Practices:
Global exception handling
Clean layered architecture (Controller → Service → Repository)
Frontend (Basic UI):
Register & Login UI
Dashboard with tasks
Perform CRUD operations
Displays API success/error responses

Tech Stack

Backend

Java
Spring Boot
Spring Security
JWT Authentication

Database

NoSQL(MongoDB)

Frontend

React (basic UI)
